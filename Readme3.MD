# K-Means Feature Engineering

## Objectif
Créer des features avancées avec K-Means clustering pour améliorer les prédictions de prix immobiliers.

## Contenu
- Scaling/Normalisation des features
- Cluster labels comme nouvelles features
- Distances aux centroïdes comme features
- Visualisation des clusters et distances

## Résultats
- Score initial : 0.180
- Avec clusters : 0.170
- Avec distances : 0.165

## Apprentissage
- Normalisation cruciale pour K-Means
- Labels de cluster → features catégorielles
- Distances aux centroïdes → capture relations complexes
